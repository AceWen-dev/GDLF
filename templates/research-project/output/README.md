# Output

Generated experiment results:

```text
output/
  runs/          # run directories (manifest, config, metrics, logs, checkpoints, evals)
  artifacts/     # content-addressed artifacts
  sweeps/        # sweep records, trial logs/results
  test_access/   # append-only test-set access log
  claims/        # reported claims (small JSON, can be committed)
  reports/       # generated Markdown reports
```

A run's training log is `logs/train.log`: timestamped epoch/step/eval/checkpoint
lines for humans. The machine-readable metrics stream is `metrics.jsonl`. A
sweep additionally captures each child process stdout/stderr in
`sweeps/<sweep_id>/trials/<trial_id>.log`.

Run directories and artifacts are generated by DLEF; never edit them by hand.
Retention is handled by `dlef gc`, not manual deletion.

A run directory contains:

```text
output/runs/<project>/<experiment>/<run_id>/
  manifest.json
  config.resolved.json
  metrics.jsonl
  logs/train.log
  tensorboard/          # when tensorboard.enabled=true
  checkpoints/
  evals/
```

The `output_root` config field controls the top-level path (default
`output`); relative values resolve against the project root. For tools/Makefile
use `OUTPUT=<path>` or export `DLEF_OUTPUT_ROOT=<path>`.

## Finding a run

Runs are grouped by project and experiment:

```text
output/runs/<project>/<experiment>/<run_id>/
```

Start with the experiment summary, then drill down:

```bash
make runs                                              # one row per experiment
make runs-all                                          # one row per run
python core/tools/runs.py --experiment baseline
python core/tools/runs.py --status completed --since 2026-10-01
python core/tools/runs.py --tag baseline
python core/tools/runs.py --json
python core/tools/run_info.py --run <run_id>
```

The summary shows, per experiment: run count, latest run, status, last metric,
best metric, tags and the last config source. `runs.py` is read-only; it never
edits a manifest. `run_info.py` then shows one run's config → source files.

For curves, start TensorBoard over the same root:

```bash
tensorboard --logdir output/runs --port 6006
# remote: tensorboard --logdir output/runs --port 6006 --bind_all
```

TensorBoard is a mirror; the files above remain the record.

## Keeping the list small

- One experiment name per comparison group. Do not create an experiment per
  smoke test; use a single `debug` or `smoke` experiment for throwaway runs.
- A seed is a run dimension, not an experiment. Three seeds = three runs in the
  same experiment.
- Tag runs that must survive cleanup when you launch them:

  ```bash
  python core/commands/train.py --config input/configs/experiments/baseline/main.yaml \
    --tag baseline --tag reported
  ```

- Retention is `dlef gc`, dry-run by default:

  ```bash
  make gc-dry
  # inspect the plan, then add --apply
  python -m dlef.cli gc \
    --runs output/runs --sweeps output/sweeps \
    --keep-last 3 --keep-best 1 --metric-key mae \
    --keep-tag reported --keep-tag baseline \
    --artifact-ttl-days 30 --sweep-ttl-days 30 --apply
  ```

Never `rm -rf output/runs/...`. `dlef gc` protects tagged runs, parents of kept
runs, sweep-referenced runs and referenced artifacts. `--sweep-ttl-days` also
removes expired sweep records whose runs are no longer kept; running sweeps are
protected.
