# Output

Generated experiment results:

```text
output/
  runs/          # run directories (manifest, config, metrics, checkpoints, evals)
  artifacts/     # content-addressed artifacts
  sweeps/        # sweep records, trial logs/results
  test_access/   # append-only test-set access log
  claims/        # reported claims (small JSON, can be committed)
  reports/       # generated Markdown reports
```

Run directories and artifacts are generated by DLEF; never edit them by hand.
Retention is handled by `dlef gc`, not manual deletion.
